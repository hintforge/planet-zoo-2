## Deluxe Edition list
TheGamesWiki: Axolotl, Blue and Gold Fusilier, **Golden Eagle**, Golden Lion Tamarin, Great Hammerhead, Longfin Batfish (and lists Western Diamondback Rattlesnake as Base) [ref 26]. Insider Gaming's Zoopedia table (Deluxe Edition column) marks exactly those six as Deluxe and the Rattlesnake as Standard, and allthings.how counts six Deluxe species (doctor 2026-10-19; see `accreditation.md`). Only a Wikily search excerpt (FAQ, never opened as text) listed **Western Diamondback Rattlesnake** in place of Golden Eagle; three sources outweigh it. Golden Eagle is Deluxe, the Rattlesnake is base game.
_source: P1 result 2026-10-19 [ref 26 (thegameswiki.com animals-and-welfare, page updated 18 Oct 2026)]; doctor Branch C 2026-10-19 [https://insider-gaming.com/planet-zoo-2-all-animals-complete-zoopedia/; https://allthings.how/planet-zoo-2-how-to-unlock-all-animals-and-accreditation-tiers/] · capture: browser_fetch · confidence: medium · enemy-tier: 0 · puzzle-tier: 0 · category: mainline · spoiler: none_ `[Corroborated: 3 sources, 1 language -- below 5-source floor]`
